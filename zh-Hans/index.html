本政策说明 iOS 与 Android 应用“林间小径 Woodland Ways”如何处理数据。发布者为 Hsu Wen-Hsun；支持与隐私联系邮箱为 17apphouse@gmail.com。

App 支持

数据收集与分享

开发者不会通过本 App 收集、接收或分享玩家数据。游戏无需账号，不使用广告、分析追踪或远程崩溃报告服务，也不会将游戏数据发送到开发者的服务器。App 不访问位置、相机、麦克风、照片或通讯录。

保存在本机的数据

App 会在设备上保存进行中的棋盘与撤销历史、已完成的最终棋盘、步数、答案帮助与预览、重新开始次数、完成标记、关卡进度、最佳成绩、印章、收藏、林地布局、自选目标与显示偏好（日夜外观与兼容模式），也会保存离线生成的新题、游玩记录与最近打开题目的顺序，以便继续游戏并避免重复出题。这些数据仅用于游戏功能与显示你的成果。

保存与恢复

有效操作及进入后台时会保存旅程，重新打开后读取本机存档。已完成题只保存最终棋盘，重新打开后不保留该题的撤销历史。写入失败时会提示重试；存档无法识别或只能部分恢复时，会保留原数据并等待你确认重建。不保证在设备故障、存储失败或数据被清除后仍能恢复存档。

系统备份与设备迁移

App 没有自有云同步，也没有存档导入或导出功能。根据操作系统与用户设置，本机数据可能被纳入设备备份或迁移；这些功能由系统提供，开发者无法获取或管理你的系统备份。请通过设备系统设置管理备份。

数据保留与删除

本机数据会保留以供之后游玩。Android 可通过系统设置清除本 App 的存储空间或数据；iOS 可通过“删除 App”移除 App 及本机数据，仅卸载 App 并保留数据的操作不会清除存档。系统备份中的副本需另外通过系统设置管理。清除或删除数据可能导致进度无法恢复；从系统备份恢复时，旧存档也可能重新出现。

支持邮件与隐私联系

如果你主动发送邮件至 17apphouse@gmail.com，发布者会收到你的发件邮箱、邮件内容以及你自行提供的附件。这些信息仅用于处理支持或隐私咨询，会保留以处理问题和后续联系，不用于广告或追踪。你可以通过同一邮箱请求删除与你来信有关的支持邮件数据。

联系发布者不会自动提供设备上的游戏存档；发布者无法远程读取或删除你的本机进度。本机数据及系统备份的删除方法如上。

本网站

如果你选择从 App 打开公开政策链接，系统浏览器会显示网页；链接不包含你的游戏存档、进度或玩家标识符。浏览器与网页托管服务会处理正常网页连接所需的技术信息。

政策与支持网页由 GitHub Pages 托管，没有加入广告、分析代码、JavaScript 或外部图片与字体。浏览网页时，GitHub 会出于安全目的记录连接 IP 地址；这与 App 的本机游戏存档不同，相关处理依据 GitHub 隐私声明进行。

政策更新

如果 App 的数据处理方式发生变化，会更新本政策与上方日期。公开政策网址为 https://iamshun.github.io/woodland-ways-privacy/zh-Hans/。
